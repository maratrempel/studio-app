# טיוטת שאלות ותשובות — לאישור לפני הטמעה

סקשן שאלות ותשובות לעמוד הבית של ivan-bobrikov.com, לפני סקשן "צור איתי קשר".
פרטים המסומנים **[להשלמה]** דורשים אישור או השלמה של איוון — לא הומצאו עובדות.

---

### 1. איך מתחילים תהליך ליווי?

פשוט: יוצרים איתי קשר בטלפון או בוואטסאפ, וקובעים שיחת היכרות. בשיחה נבין ביחד מה המטרות שלך, מה הרגלי התזונה והאימון הנוכחיים שלך, ונבנה נקודת פתיחה. אין צורך בהכנה מוקדמת — מגיעים כמו שאתם.

### 2. כמה זמן לוקח לראות תוצאות?

זה תלוי בנקודת הפתיחה וביעדים, אבל רוב המתאמנים שלי מרגישים שינוי באנרגיה ובהרגשה כבר בשבועות הראשונים, ורואים תוצאות נראות לעין תוך **[להשלמה: טווח זמן מדויק, למשל 8–12 שבועות]**. תהליך אמיתי הוא לא דיאטת בזק — המטרה היא שינוי שנשאר.

### 3. האם צריך מנוי לחדר כושר?

לא חובה. תוכנית האימונים נבנית לפי התנאים שלך — חדר כושר, אימונים בבית או בחוץ. מה שחשוב זה ההתמדה, לא הציוד.

### 4. האם הליווי מתאים למתחילים?

בהחלט. חלק גדול מהמתאמנים שלי מתחילים מאפס, בלי רקע באימונים או בתזונה מסודרת. התוכנית נבנית בדיוק לפי הרמה שלך ומתקדמת בקצב שלך.

### 5. מה כולל הליווי האישי?

הליווי כולל תוכנית תזונה אישית, תוכנית אימונים מותאמת, מעקב שוטף והתאמות לאורך הדרך, וזמינות שלי לשאלות בוואטסאפ. **[להשלמה: לאשר את הרכיבים המדויקים — האם יש שקילות/מדידות במשרד? תדירות מפגשים?]**

### 6. האם יש התאמה לתזונה צמחונית?

כן. תוכנית התזונה נבנית סביב ההעדפות והמגבלות שלך — צמחונות, רגישויות, כשרות או כל צורך אחר. **[להשלמה: לאשר שזה נכון גם לטבעונות]**

### 7. מה העלות של הליווי?

העלות תלויה בסוג התהליך ובמשך הליווי. **[להשלמה: להחליט — לציין מחיר/טווח מחירים, או להשאיר "בשיחת ההיכרות נתאים מסלול ומחיר"]**

### 8. האם יש מעקב גם אחרי סיום התהליך?

**[להשלמה: לאשר עובדתית — האם יש שיחת מעקב / ליווי המשך / קבוצת בוגרים?]** המטרה שלי היא שתצאו מהתהליך עם כלים שנשארים איתכם לכל החיים, לא תלות בי.

## FAQPage Schema (יוטמע אחרי אישור הטיוטה)

יש להטמיע JSON-LD מסוג `FAQPage` עם אותן שאלות ותשובות בדיוק (בנוסח הסופי המאושר), למשל:

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "איך מתחילים תהליך ליווי?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "יוצרים קשר בטלפון או בוואטסאפ וקובעים שיחת היכרות..."
      }
    }
  ]
}
```

חשוב: הטקסט ב-Schema חייב להיות זהה לטקסט המוצג בעמוד, אחרת גוגל עלול להתעלם ממנו.
