# משק דוד — אתר חדש (שלב פרונט-אנד)

בנייה מחדש של meshekdavid.com (כרגע ב-Wix), כאב-טיפוס סטטי שיומר לוורדפרס ו-WooCommerce.

## הרצה מקומית
```bash
python3 build.py                  # בונה את העמודים מ-src/
python3 -m http.server 8000       # ואז http://localhost:8000/index.html
```
**לעולם לא עורכים את קובצי ה-HTML שבשורש.** עורכים רק את `src/pages/*.html` ואת `src/partials/*.html`, ומריצים `build.py` מחדש.

## מבנה
| נתיב | תפקיד | המקבילה בוורדפרס |
|---|---|---|
| `src/partials/header.html`, `footer.html` | כותרת, סרגל נגישות, פוטר עם תפריט מהיר | `header.php` / `footer.php` |
| `src/pages/*.html` | תוכן העמודים | עמודים / תבניות |
| `assets/js/data.js` | מוצרים, קטגוריות, יישובים, הגדרות משלוח | מוצרי WooCommerce + הגדרות הפלאגין `md-delivery` |
| `assets/js/store.js` | עגלה, פרופיל, חישוב מועד משלוח | WC Cart / Customer + `md-delivery` |
| `assets/js/combobox.js` | שדה יישוב עם השלמה אוטומטית (ARIA) | אותו רכיב, בקופה ובחלון |
| `assets/js/shop.js` | חלון בדיקת יישוב, סינון, תצוגה מהירה | תבנית archive-product |
| `assets/js/checkout.js` | קופה: יישוב לפני רחוב, מתנה, כתובת אחרת, דיוור | `woocommerce_checkout_fields` |
| `assets/js/account.js` | אזור אישי, הזמנה חוזרת, מחיקת מידע | My Account |

## מוצרים: יחידה לעומת משקל
- `sale_type: "unit"`: הכמות נבחרת ביחידות (1, 2, 3...).
- `sale_type: "portion"`: הגבינה נחתכת, והכמות נבחרת במנות של `portion_grams` (150, 300, 450 גרם...). המחיר קבוע למנה, וזו ההמלצה שאושרה.

⚠️ צריך לאמת מול המשק אילו גבינות שלמות ואילו נחתכות. כרגע שירה, ירדן, רות, אורלי ותל קקון מוגדרות כנחתכות.

## מועד משלוח
הזמנה עד יום רביעי ב-12:00 (שעון ישראל) מגיעה ביום חמישי אחה"צ וערב. אחרי המועד הזה ההזמנה עוברת לשבוע הבא. ההגדרה נמצאת ב-`MD.settings` בקובץ `data.js`.
